# Map Packs to Hall of Fame

This mod, like the title says, replaces the Map Packs button by the Hall of Fame one! (Of course, not the sprite only, the interface of Map Packs!) You see the Map Packs, everyone hates it (even me) and everyone wants Map Packs disappears from the game. Well, if you want that tho, this mod is for you! This mod not only delete the Map Packs, but replaces it by a button forgotten by RobTop and existed in 2.1: The Hall of Fame (Featured but Epic Only), MUCH better than Map Packs!

## "Okay, but there is already BetterInfo for that, so no need it lol!"

Yes, I totally know BetterInfo adds Hall of Fame tho. But like I said, it also replaces the fu****g Map Packs by Hall of Fame! Much Better!
Also the button will be on Creator layer like it was in 2.1 and not on the BetterInfo Layer.

# Other

## BetterInfo

For showing the "Hall of Fame" title, [BetterInfo](https://geode-sdk.org/mods/cvolton.betterinfo) will be required for it. But BetterInfo is not really required for the mod and it will not cause bugs if you don't have it. Just the "Hall of Fame" title will not be shown, so that's not an dependencie.
If you want the title but you don't have this mod, than just install it.
